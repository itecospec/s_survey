Ecospec Site Survey installable app

This corrected package uses the actual Ecospec logo embedded in the original HTML.

How to install:
1. Upload this folder to a HTTPS web host.
2. Open index.html in Chrome or Safari on the phone.
3. Tap Share / menu, then Add to Home Screen or Install app.

Files included:
- index.html
- manifest.webmanifest
- service-worker.js
- ecospec-logo.png
- icons generated from the real Ecospec logo mark
